Definitions

Rook polynomials are a mathematical tool used to count the number of ways of placing non-attacking rooks on a board, including boards where some squares are restricted.

♜ Rook

A rook is a chess piece that can move any number of squares horizontally or vertically.

Restricted Board

A restricted board is a board in which certain squares cannot be used for placing rooks.

Non-Attacking Rooks

Rooks are non-attacking when no two rooks are placed in the same row or the same column.

Rook Number

The rook number rk is the number of ways to place k non-attacking rooks on the allowed squares of a board.

Rook Polynomial

If rk represents the number of ways to place k non-attacking rooks, then the rook polynomial of a board B is:

RB(x) = r0 + r1x + r2x2 + ... + rnxn

Here, r0 = 1 because there is exactly one way to place zero rooks: place no rooks at all.

Formulas for Calculating Rook Numbers

Rook Polynomial Formula

RB(x) = r0 + r1x + r2x2 + ⋯ + rnxn

RB(x) is the rook polynomial of board B. The number r0 is always 1 because there is exactly one way to place zero rooks: place no rooks. Each rk counts the ways to place k non-attacking rooks, and x is a variable used in the polynomial.

For a complete 3 × 3 board:

RB(x) = 1 + 9x + 18x2 + 6x3

Formula for a Complete Rectangular Board

rk = C(m, k) × C(n, k) × k!

This formula applies to a complete rectangular board with no restricted squares. m is the number of rows, n is the number of columns, and k is the number of rooks.

C(m, k) means choosing k rows from m rows, and C(n, k) means choosing k columns from n columns. Finally, k! counts the ways to pair the selected rows and columns to place the rooks.

For boards with restricted squares, calculate the rook numbers using only the available squares.
