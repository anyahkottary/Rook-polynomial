Definitions

Rook polynomials are a mathematical tool used to count the number of ways of placing non-attacking rooks on a board, including boards where some squares are restricted.

♜ Rook

A rook is a chess piece that can move any number of squares horizontally or vertically.

Restricted Board

A restricted board is a board in which certain squares cannot be used for placing rooks.

Non-Attacking Rooks

Rooks are non-attacking when no two rooks are placed in the same row or the same column.

Rook Number

The rook number rk is the number of ways to place k non-attacking rooks on the allowed squares of a board.

Rook Polynomial

If rk represents the number of ways to place k non-attacking rooks, then the rook polynomial of a board B is:

RB(x) = r0 + r1x + r2x2 + ... + rnxn

Here, r0 = 1 because there is exactly one way to place zero rooks: place no rooks at all.

Examples

The following example shows how rook numbers are calculated for a complete 3 × 3 board and how they are used to form the rook polynomial.

Example Board: 3 × 3 Board

Example 1: Placing One Rook

A 3 × 3 board has a total of 9 squares. When placing only one rook, it can be placed on any of these 9 squares.

Therefore, the number of ways to place one rook is:

r1 = 9

Example 2: Placing Two Rooks

Two rooks must not be placed in the same row or the same column.

First, choose 2 different rows. There are 3 possible pairs of rows:

(Row 1, Row 2), (Row 1, Row 3), (Row 2, Row 3)

Similarly, there are 3 possible pairs of columns.

For each selected pair of rows and columns, the two rooks can be arranged in 2 different ways.

r2 = 3 × 3 × 2 = 18

Therefore, there are 18 ways to place two non-attacking rooks on a 3 × 3 board.

Example 3: Placing Three Rooks

When placing three rooks on a 3 × 3 board, each rook must occupy a different row and a different column.

The first rook has 3 choices. After choosing its row and column, the second rook has 2 choices, and the third rook has 1 choice.

r3 = 3 × 2 × 1 = 6

Therefore, there are 6 ways to place three non-attacking rooks.

Complete Rook Polynomial

We also have:

r0 = 1

There is exactly one way to place zero rooks: place no rooks on the board.

Therefore, the rook numbers for the complete 3 × 3 board are:

r0 = 1,   r1 = 9,   r2 = 18,   r3 = 6

Substituting these values into the rook polynomial:

RB(x) = 1 + 9x + 18x2 + 6x3

This polynomial represents the number of ways to place different numbers of non-attacking rooks on the board.
